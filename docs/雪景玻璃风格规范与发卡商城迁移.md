# 雪景玻璃风格规范与发卡商城迁移

整理日期：2026-09-05。参考站点：https://hanbala.dpdns.org/ 。代码基线：a8e8372949e7da9283648226dd07b845c2e0aac0。

目标：将韩序博客已确认的雪景、半透明玻璃面板、独立导航和轻量动效迁移到 CFFK 发卡商城。沿用商城名称、商品信息与交易流程，不复制博客的文章栏目或宣传文案。

## 1. 整体视觉

全屏雪山或雪村摄影作为背景，冷色雪景搭配夕阳暖光。背景 cover 铺满、居中裁切，叠加渐变暗罩保证白色文字可读。面板使用低透明度填充、细白色边框、柔和外阴影和顶部内高光。页面留白充足，内容依附独立卡片，避免文字直接挤在风景上。

首页与欢迎页的主要面板固定为0%虚化。0%只表示不模糊，仍保留透明填充、边框、高光与阴影。内页首次默认5%，用户选择继续记住。

## 4. 虚化行为：以此最终规则为准

- 固定档位：0、5、15、30、45、60、75、90、100%，点击依序循环，100%后回到0%。
- 换算：虚化像素 = 百分比 × 42 / 100。5%即2.1px，100%即42px。
- 欢迎页中间板和商城主页主要面板固定0%，不受内页设置影响。
- 内页无保存记录时默认5%；已有记录则恢复用户档位，刷新和切页不重置。
- 旧保存值换算到最近的新档位；等距时采用较低档位。
- 按钮显示百分比，提供说明与无障碍名称。博客主页按钮显示0%并禁用；商城可沿用。
- 首页独立覆盖自身作用域的虚化变量，不把0写回内页偏好。商城使用自己站点的存储键。

## 5. 布局与组件

顶部左侧品牌是一块独立玻璃板，点击回商城首页；右侧菜单在另一块玻璃板中，中间留空，不连成一整条。公共页保持一致导航，手机端收进可键盘操作的菜单。博客最大内容宽1100px、两侧至少16px；商城后台按表格所需宽度适配。

主按钮使用白底深色文字，次按钮用透明底细白边框。卡片内边距约20px，桌面28px；标题、说明和底部操作分层，操作区上方有细分隔线。文字保持清晰层级，沿用商城已有字体，必要时加轻微文字阴影，不把博客字号强行套在密集后台表格上。

| 博客视觉元素 | 商城对应位置 |
| --- | --- |
| 首页主视觉板 | 商城品牌介绍、公告、主要入口 |
| 主题分类卡 | 商品分类入口 |
| 独立文章卡 | 商品卡：名称、说明、价格、库存、购买入口 |
| 文章内页玻璃大板 | 商品详情、订单查询、关于页面 |
| 博客后台玻璃工作区 | 商城后台布局、筛选区、表格和表单的视觉参考 |

商品卡保留商城实际所需字段；缺货、加载、错误、空列表各有明确状态。文章“每类最新一篇”的内容规则是博客功能，不自动复制到商城。现有公共导航需要的商城入口和账号入口照常保留。

## 6. 动效

普通路由切换采用约180ms ease-out 淡入淡出。顶部导航不再每次播放560ms下滑入场动画。不叠加整页缩放或长时间滑入，避免毛玻璃合成时显得拖沓。卡片悬停可轻微上移2–3px，交互时长约180ms。

博客使用 Astro ClientRouter 和原生 View Transition；商城按其框架采用等效方式，不为照搬实现而更换框架。支持 prefers-reduced-motion。博客欢迎页保留原先雪景、文字渐入和进入按钮；商城不默认新增阻挡购买的全屏欢迎流程，如已有欢迎页则使用上述固定0%规则。

## 7. 实施与验收

先检查 CFFK 实际仓库、框架、主题入口与现有修改；复用已有布局、组件和样式变量。优先完成公共商城首页、分类和商品详情，再验证订单查询及交易表单的视觉一致性。后台可作为第二阶段适配，保持原有管理结构。

本次为视觉改版：支付、价格计算、库存、下单、自动发卡、登录和供应商接口等业务逻辑保持现有行为。无需新建支付/订单实现或更换项目架构。提交和部署遵循商城任务中有效的授权范围。

验收：320/768/1024/1440px无横向溢出；品牌回首页正确；菜单可键盘使用；价格/状态/表单清楚可读；首页0%与内页5%偏好隔离；切页后菜单、主题和虚化按钮可用；减少动态效果生效；不产生重复事件绑定。运行商城原有测试和构建，并提供本地浏览器预览供用户检查；不执行真实支付或消耗卡密来验证视觉。
